# Fleet Start — privacy policy

This repository exists only to publish the privacy policy for the **Fleet Start**
iOS and Android app at a public URL, as required by the App Store and Google Play.

The page is served at
<https://mattiasbowallius.github.io/fleet-start-privacy/>.

The app's source lives in a separate private repository. To change this policy,
edit `index.html` here and in `store/PRIVACY.md` / `docs/index.html` in the app repo.
